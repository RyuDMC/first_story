Storytelling with data for https://github.com/RyuDMC/Data-Science_First_Proyect

Los archivos `index.html`, `datos.js`, `datos.json` y `og.png` se copian desde
`historia/` de ese repo, donde se generan con:

```bash
python3 codes/generar_historia.py        # datos.json + datos.js
python3 codes/generar_historia.py --og   # og.png (tarjeta social)
```

No se editan a mano aquí: se regeneran en el repo fuente y se replican.
